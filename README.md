# 📚 E-Library Management System

A comprehensive web-based application designed to modernize and streamline digital and physical library management. Built with **ASP.NET** and **C#**, this system automates common library functions, making it easier for both administrators and users to interact with the library resources efficiently.

---

## 🛠️ Technology Stack

- **Frontend**: HTML, CSS, Bootstrap, JavaScript  
- **Backend**: ASP.NET, C#  
- **Database**: MS-SQL Server

---

## 🔑 Key Features & Modules

- ✅ **Member Signup**: New users can register accounts  
- ✅ **Member Login**: Existing users can log in  
- ✅ **Admin Login**: Secure login for administrator access  
- ✅ **View Books**: Members can view available books  
- ✅ **Author Management**: Admin can Add/Update/Delete authors  
- ✅ **Publisher Management**: Admin can manage publishers  
- ✅ **Book Inventory**: Full CRUD operations on books  
- ✅ **Book Issuing System**: Issue and return books functionality

## 💡 Purpose

To replace traditional library operations with an efficient, centralized, and user-friendly digital solution that simplifies resource management and enhances the user experience for both members and administrators.

## 🚀 Getting Started

1. Clone the repository  
   ```bash
   git clone https://github.com/Adityarrudola/E-Library-Management-System.git
   ```

2. Open the project in **Visual Studio**

3. Set up your **SQL Server** database and update the connection string

4. Run the project on **IIS Express** or any .NET-compatible server

---

## ⚙️ Requirements

- Visual Studio 2019 or later  
- .NET Framework 4.5+  
- MS SQL Server
